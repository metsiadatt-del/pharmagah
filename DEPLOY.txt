فارم‌آگاه — راهنمای انتشار و نگهداری

انتشار مستقیم روی GitHub Pages (بدون نیاز به بیلد)
۱. یک مخزن GitHub بسازید.
۲. محتویات فایل ZIP را استخراج کنید و همهٔ فایل‌ها و پوشه‌ها را در ریشهٔ مخزن قرار دهید؛ index.html باید در ریشه باشد، نه داخل پوشهٔ اضافی.
۳. فایل‌های assets، src، tests، package.json، package-lock.json، build.mjs، sw.js و manifest.webmanifest را همراه فایل‌های دیگر نگه دارید.
۴. در تنظیمات مخزن به Settings → Pages بروید. در بخش Build and deployment گزینهٔ Deploy from a branch را انتخاب کنید؛ شاخهٔ main و پوشهٔ / (root) را انتخاب و ذخیره کنید.
۵. پس از پایان انتشار، آدرس HTTPS نمایش‌داده‌شده در همان صفحه را باز کنید. این بسته خودش در GitHub منتشر نشده است.
۶. برای اولین ذخیرهٔ آفلاین، یک بار بارگذاری کامل با اینترنت لازم است. بازکردن مستقیم index.html با file:// جایگزین انتشار HTTPS نیست.

ویرایش و آزمون
فایل‌های اصلی در src هستند و assets حاوی نسخهٔ آمادهٔ انتشار است.
نسخهٔ پیشنهادی Node.js: نسخهٔ ۲۲ یا بالاتر (به‌علت نیاز یکی از وابستگی‌ها).
فرمان‌ها به‌ترتیب:
  npm ci
  npm run check
  npm run build
  npm test
پس از تغییر src، نسخهٔ تازهٔ assets را هم در مخزن ثبت کنید.
پس از تغییر فایل‌های آفلاین، نام نسخهٔ کش را در sw.js و src/app.js هماهنگ افزایش دهید و دوباره build بگیرید؛ نسخهٔ فعلی pharmagah-v2 است.

ساختار بسته
index.html: ورودی سایت
src/app.js و src/core.js: رابط و منطق جست‌وجو و گزارش
src/style.css: طراحی راست‌به‌چپ، رنگ‌ها، تایپوگرافی و چاپ
assets/: فایل‌های آماده، فونت فارسی محلی و مجوز فونت
sw.js: ذخیرهٔ پوستهٔ برنامه برای استفادهٔ آفلاین
manifest.webmanifest: مشخصات وب‌اپ
tests/: آزمون منطق، تعاملات DOM و رفتار آفلاین
package-lock.json: نسخه‌های دقیق وابستگی‌ها

فونت و منابع
فونت Vazirmatn به‌صورت محلی داخل assets قرار دارد و برای نمایش نیاز به CDN ندارد. مجوز آن در assets/FONT-LICENSE.txt همراه بسته است. نمادهای رابط SVG داخلی‌اند؛ تصویر یا فونت راه‌دور نیاز نیست.

حریم خصوصی و محدودیت‌ها
گزارش و یادداشت در localStorage همین مرورگر ذخیره می‌شود؛ سرور، حساب کاربری و همگام‌سازی ابری وجود ندارد. قبل از تغییر دستگاه، دامنه یا پاک‌کردن داده‌های مرورگر از تنظیمات برنامه نسخهٔ پشتیبان JSON بگیرید.
جست‌وجو آنلاین است و عبارت علمی به Europe PMC ارسال می‌شود. اطلاعات هویتی بیمار وارد نکنید.
تحلیل هوشمند بالینی، ترجمهٔ تخصصی و دسترسی به UpToDate و کتاب‌های اشتراکی متصل نیست؛ هیچ تضمین کیفیت یا تشخیص و درمان خودکار ارائه نمی‌شود.
خروجی Word مستقیم است. برای PDF از «چاپ / PDF» و گزینهٔ Save as PDF در پنجرهٔ چاپ استفاده کنید.

آزمون و تحویل
آزمون‌ها بدون مرورگر اجرا می‌شوند؛ آزمون DOM با jsdom به‌معنای تأیید بصری صفحه نیست. قبل از استفادهٔ عملی، ظاهر در تلفن و دسکتاپ، جست‌وجو، ذخیره/بازیابی، خروجی Word و چاپ PDF و بارگذاری آفلاین را روی آدرس منتشرشده بررسی کنید.
بسته فاقد node_modules، تاریخچهٔ Git، فایل‌های محیط داخلی و اطلاعات کاربری است؛ وابستگی‌های توسعه با npm ci نصب می‌شوند و برای انتشار مستقیم نیازی به نصب آن‌ها نیست.
